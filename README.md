## 同一個價錢，香港為什麼只有 10Mbps

香港機房的帶寬資源成本高，同一筆錢能買到的帶寬自然比美國機房少。這話是行業層面的解釋，不是某一家商家的定價策略。放到 LightLayer 的價目表上看就很直觀：$24.99 這條線，香港給 10Mbps，洛杉磯給到 200Mbps，差二十倍。

所以你買香港年付機，買到的主要是地理位置和線路品質，帶寬被壓得很低。10Mbps 換算下來大約 1.25MB/s，實際傳輸還要打個折。

- 放一個文字為主的企業站、部落格、展示頁：夠。頁面幾百 KB，十個人同時開也不會卡死。
- 做 SSH 跳板、內網穿透、遠程管理：夠，這類用途吃的是延遲不是帶寬。
- 備份同步、圖片站、影片站、鏡像下載：不夠，10Mbps 會成為瓶頸。
- 看 4K 串流、跑大流量爬蟲：不夠，而且這一檔本來也不是為此設計的。

計費邏輯也要看清楚。香港這檔寫的是「10Mbps 不限流量」，洛杉磯 200Mbps 那檔寫的是「200Mbps、1TB 月流量」。前者是限速不限量，後者是限量不限速。超了 1TB 之後怎麼算，公開頁面沒有寫清楚，如果你的用量會頂到上限，下單前先問客服，別自己猜。

## 非原生 IPv4 是這檔香港機最該留意的地方

同樣 $24.99，香港、台灣、新加坡的年付方案配的是**非原生 IPv4**，洛杉磯配的是原生 IPv4。

原生 IP 的通行定義是 IP 的註冊地與機房所在地一致；非原生（常說的廣播 IP）則是註冊地不在機房所在國。對一般建站、遠程、跳板用途，這個差別幾乎感覺不到。對需要「被判定為香港本地用戶」的服務，差別就大了：港區串流平台、本地票務、部分電商與社媒的風控，都會看 IP 歸屬地。

所以這一檔香港機的定位要擺正。它解決的是「機器放在香港、延遲低、不用備案」，不是「給我一張香港身份證」。想解鎖 TVB、Netflix 港區、或做港區社媒賬號運營，非原生 IP 的成功率明顯不如原生 IP，更不如住宅 IP。這類需求要先跟客服確認有沒有對應的 IP 類型，別買完才發現方向錯了。

## 三種用途，三種選法

**免備案建站。** 香港節點不在大陸監管範圍內，開通即用，不需要 ICP 備案，這一點在幾個來源裡說法一致。1GB 記憶體跑靜態站、輕量 CMS、小型論壇後台都行；WordPress 裝十幾個插件再加 MySQL，1GB 會吃緊，選之前先確認有沒有更高規格的香港檔位。日流量幾千 PV 的站，10Mbps 不是瓶頸；瓶頸會先出現在記憶體上。

**中轉與遠程。** 香港到華南的物理距離短，三網直連的情況下延遲通常標稱在 30～50ms，歐美機房動輒 200ms 以上。這個延遲水平做 SSH、遠程桌面、API 中轉、內網穿透都舒服。10Mbps 帶寬配合不限流量，跑監控、跑小規模同步都不心疼。

順帶把線路術語解釋一次。電信去程走 CN2、聯通去程走 9929、移動去程走 CMIN2，是「三網精品線路」的常見組合；CMI 是移動的國際出口，普通國際線路則是大夥排隊走的公共交通。LightLayer 的香港年付方案只標了「優化線路」，沒有說明具體走哪幾條，這一點頁面沒寫就不能替它補。要確認，問客服要路由測試 IP。

**港區內容與跨境賬號。** 參考上一節，非原生 IP 不是為這個場景準備的。真要做，先確認原生或住宅 IP 的方案存在，再談價格。
